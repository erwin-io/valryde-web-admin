# Architecture Documentation

This area will hold the Valryde Admin module architecture after the full development directive.

Planned document: `ADMIN_MODULE_ARCHITECTURE.md`, covering Angular application boundaries, feature areas, core services, routing, state ownership, authentication/session handling, configuration, error handling, and deployment assumptions.

Architecture must preserve the backend as the authority for RBAC, route assignment, GPS workflows, and tracking eligibility. No application architecture has been selected beyond the approved Angular/Material/CDK/TypeScript/MapLibre baseline.
