# Visual Acceptance

## Shell

- Toolbar remains visible while content scrolls.
- Drawer is persistent and collapsible at desktop widths and becomes an accessible overlay below 960 px.
- Keyboard focus order follows toolbar → drawer → page heading → content.
- Active navigation is unambiguous in expanded and collapsed modes.

## Pages

- Each page has one title, concise purpose text, and no more than one primary action.
- Tables remain usable at 1024 px; secondary columns may collapse, but identity/status/actions remain available.
- Forms stack cleanly on tablet, display field errors next to their cause, and preserve values after recoverable server errors.
- Loading, empty, filter-empty, error, denied, blocked, and stale states are visually and semantically distinct.

## Accessibility

- Interactive targets are at least 44 px where practical.
- Text and controls meet WCAG AA contrast.
- Icon-only controls have accessible names and tooltips.
- Status is expressed in text, not color alone.
- Dialogs trap focus and return focus to their trigger.
- Motion respects reduced-motion preferences.

## Prohibited presentation

No gradients, glassmorphism, ornamental charts, oversized metric cards, invented KPIs, dense multi-purpose forms, or production navigation to contract-blocked modules.
