# UI/UX Documentation

This area will hold:

- `NAVIGATION_STRUCTURE.md`
- `SCREEN_INVENTORY.md`
- `COMPONENT_CATALOG.md`
- `ADMIN_WORKFLOWS.md`
- `MAP_AND_GEOMETRY_EDITING_RULES.md`

The baseline is a professional, collapsible Angular Material navigation drawer with clear headings, focused screens, tables with contract-supported search/filter/pagination, dedicated details, structured forms, contextual navigation, accessible status badges, and explicit loading/empty/error/retry states.

Avoid decorative gradients, unnecessary charts, deeply nested menus, oversized cards, and unrelated responsibilities in one form. A formal stop-registry screen is not authorized by the current MVP scope.
